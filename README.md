# Look What You Did

后端代码通用 Codex Skill 仓库。

## Skill

`write-branch-change-doc`：审查当前分支相对基线的接口、调用流程、文件、数据库和新增测试，并生成 Markdown 变更说明。

使用：

```text
使用 $write-branch-change-doc 生成当前分支的变更说明。
```

## 输出格式

最终文件输出到代码仓库根目录下，结构如下：

```markdown
# [功能名]（[一句话限定]）分支变更说明

## 一、简介
## 二、接口文档
## 三、修改代码涉及入口
## 四、修改内容
## 五、表结构的修改
## 六、测试覆盖情况
```

章节内容：

| 章节 | 内容 |
| --- | --- |
| 简介 | 新增、修改、删除的能力和配置。 |
| 接口文档 | 请求体、返回体及字段变化。 |
| 修改代码涉及入口 | HTTP、RPC、Webhook、Consumer、Scheduler 等调用流程图。 |
| 修改内容 | 每个变更文件的业务职责、当前逻辑和之前逻辑。 |
| 表结构的修改 | 字段、约束、索引及迁移来源；无变更时写“无”。 |
| 测试覆盖情况 | 本分支新增测试及其业务场景。 |

接口使用完整 JSON，流程图使用 Mermaid。文档只描述本次分支差异，不输出未变化逻辑、测试执行说明或后续计划。
